How it works

Seven stages. Nothing is reported as working until it has been observed working.

1Detect

Finds installed agents and reads your project stack — with the file that proves each signal.

2Recommend

Deterministic rules, not a model. You can read them and predict the output.

3Compile

One capability definition becomes JSON, TOML and JSONC — each written surgically.

4Install

Configs are backed up first. Credentials are requested only where declared.

5Verify

Each server is launched and asked for its tool list. Not "we wrote a file".

6Manage

Switch a capability off without uninstalling it. Context cost is measured, not guessed.

7Roll back

Restores original bytes, keeps edits you made afterwards, refuses when it cannot prove ownership.

Before you install

What it needs.

  • Windows x64. macOS and Linux aren't supported yet.
  • Node.js 22.17+ with npm on PATH. The app bundles Electron, but launches MCP servers with your Node.
  • Internet on first install, to fetch MCP packages.
  • It writes to your real agent configs. Every write is backed up and reversible — or pass --demo for a sandbox.

What it won't claim

Stated, not hidden.

  • A healthy server means it started and returned a tool list — not that your credentials are valid.
  • Plugin status reads Configured, never Verified. A plugin loads inside the agent, out of reach.
  • Context figures are estimates — schema characters ÷ 4, not billed tokens.
  • Release binaries are unsigned.
